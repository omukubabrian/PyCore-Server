# PyCore Server

PyCore Server is a Python backend project built with Flask. It is designed to provide a foundation for learning server development, REST APIs, database integration, frontend communication, and deployment.

## Objectives

- Understand how HTTP servers work.
- Build REST API endpoints using Flask.
- Exchange data using JSON.
- Learn request handling and input validation.
- Integrate a database such as MySQL or PostgreSQL.
- Connect frontend applications to the backend.
- Practice Git and GitHub version control.
- Deploy the application when it is ready.

## Technologies

- Python
- Flask
- HTTP and JSON
- Git and GitHub

## Development Setup

1. Clone or download the project.
2. Create and activate a Python virtual environment.
3. Install dependencies using `python -m pip install flask`.
4. Start the development server using `python app.py`.
